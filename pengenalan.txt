Logging
log file adalah file yang berisikan informasi kejadian dari sebuah sistem
biasanya dalam log file terdapat informasi waktu kejadian dan pesan kejadian 
logging adalah aksi menambah informasi log ke log file
logging sudah menjadi standard industri untuk menampilkam informasi yang terjadi di aplikasi yang kita buat 
logging juga bukan hanya untuk menampilkan informasi, kadang di gunakan untuk proses debugging ketika terjadi masalah di aplikasi kita.

Nodejs logging
nodejs sendiri sebenarnya memiliki fitur untuk melakukan logging dengan object console 
namun saat ini, kebanyakan programer hanya menggunakan fitur ini padaq kasus-kasus yang sederhana
hal ini dikarenakan penggunanya yang kurang flexsibel dan minim fitur.

Logging Liberary 
di luar nodejs logging banyakm sekali liberary yang bisa kita guankan untuk logging seperti:
WINSTON
BUNYAN
PINO
LOGLEVEL
NPMLOG

Wnston 
untuk saat ini kita akan belajar menggunakan winston 
winston merupakan logging liberary yang sangat populer dikalangan programer nodejs
