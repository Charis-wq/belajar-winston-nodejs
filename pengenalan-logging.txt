Logging
log file adalah file yang berisikan informasi kejadian dari sebuah sistem
biasanya dalam log file terdapat informasi waktu kejadian dan pesan kejadian 
logging adalah aksi menambah informasi log ke log file
logging sudah menjadi standard industri untuk menampilkam informasi yang terjadi di aplikasi yang kita buat 
logging juga bukan hanya untuk menampilkan informasi, kadang di gunakan untuk proses debugging ketika terjadi masalah di aplikasi kita.

Nodejs logging
nodejs sendiri sebenarnya memiliki fitur untuk melakukan logging dengan object console 
namun saat ini, kebanyakan programer hanya menggunakan fitur ini padaq kasus-kasus yang sederhana
hal ini dikarenakan penggunanya yang kurang flexsibel dan minim fitur.

Logging Liberary 
di luar nodejs logging banyakm sekali liberary yang bisa kita guankan untuk logging seperti:
WINSTON
BUNYAN
PINO
LOGLEVEL
NPMLOG

Wnston 
untuk saat ini kita akan belajar menggunakan winston 
winston merupakan logging liberary yang sangat populer dikalangan programer nodejs

Logger
logger adalah sebuah object di winston, yang digunakan untuk melakuakan logging
untuk membuat object logger kita bisa menngunakan function creatLogger() yang terdapat di package/module winston

Console Transport
saat membuat logger secara default logger tidak akan menggunakan transport 
apa itu transport? transport adalah destinasi atau target 
yang di gunakan untuk mengirim log 
ada banyak sekali transport yang paling sederhana adalah console 
console merupakan transport yang digunakan untuk mengirim data log ke console/stdout.

Logging Level 
Level 
dalam logging terdapat istilah yang bernama level, biasanya digunakan sebagai informasi seberapa penting log tersebut
level di mulai dari yang paling rendah ke paling tinggi semakin tinggi levelnya artinya semakin penting informasi log tersebut 
untuk menambahkan level ketika melakukan log kita bisa ubah attribut level menjadi level yang kita inginkan

Winston Level:
error: untuk error
warn: untuk peringatan
info: untuk memberitahu info
http: untuk memberitahu tentang http
verbose: untuk melihat detail verbose 
debug: untuk memeberitahu debugging
silly: untuk pengujian saja

secara default saat kita membuat logger hanya akan menampilkan log dengan level info atau level di atasnya
jika kita ingin merubah log level dan mana yang kita ingin tampilkan maka kita perlu ubah konfiigurasi level ketika kita membuat logger dengan menggunakan level minimal yang ingin kita tampilkan

Shortcut function
logger juga memiliki function shortcut yang bisa digunakan untuk melakukan logging sehingga kita tidak perlu menggunakan function log dan object dengan attribute level lagi 
kita bisa langsung menggunakan function dengan nama sesuai dengan levelnyamisal logger.info(mesaage). 

Format
format adalah object yang digunakan untuk melakukan formating data log sebelum dikirim ke transport
saat kita membuat logger secara default logger akan menggunakan json format artinya data akan dikirim dalam bentuk json 
winston juga menyediakan banyak format lain selain json

Membuat Format sendiri
winston juga menyediakan format printfyang bisa kita gunakan untuk membuat formatt sendiri.

Comboain Format
winston memiliki fitur bernama combine format dimana kita bisa melakukan  kombinasi beberapa format sekaligus
ini cocok untuk menambah informasi tambahan ke log data misal data timestamp data jarak waktu dan lain-lain
kita bisa menggunkan combine format di winston untuk menggabungkan beberap format.

File Transport
dari namanya kita sudah tau bahwa transport ini akan menyimpamn data log ke file 
kita bisa menambahkan langsung beberapa transport dalam satu loggger object.

Default Transport File
secara default winston transport file hanya menyimpan semua log di dalam satu file.
hal ini akan sangat berbahaya ketika aplikasi berjalan dalam jangka waktu yang lama, sehingga menyebabkan ukuran file akan makin membesar.

Daily Rotate File 
untungnya winston membuat package terpisah untuk membantu yaitu daily rotate file.
package ini bisa digunaKn untuk membuat rotasi file transport secara ototmatis sesuai aturan yang kita tentukan dan bisa secara otomatis menghapus file lama kita yang sudah tidak di perlukakn lagi.

Membuat Transport
kadang pada kasus tertentu mungkin kita ingin membuat transport sendiri misalnya ada log error kita ingin mengirim data tersebut ke database atau ke chat atau email dan lain-lain.
jika tidak ada transport yang tersedia secara default oleh winston kita bisa membuat transport sendiri secara manual jika kita mau.
untuk membuat transport kita cukup membuat class turunan dari package winston transport.

Exception
saat kita membuat program nodejs kadang kita lupa menangkap Exception
hal ini bisa berbahaya karena nanti kita tidak bisa melakukan debug exception dengan baik sehingga kita tidak bisa menginvestigasi selanjutnya.

Handle Exception
winston memiliki fitur otomatis yang bisa digunakan untuk menangkap exception yang belum terhandle 
kita bisa melakukan pengaturan ini di logger yang secara otomatis exception akan dikirim kesemua transport 
atau kita bisa lakukan pengaturan di transport.
